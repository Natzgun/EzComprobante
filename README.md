# EzComprobante

App web para convertir XML de SUNAT en un comprobante visual limpio y listo para imprimir o exportar a PDF.

## Qué hace
- Lee el XML localmente en el navegador.
- Extrae datos del comprobante y los presenta en una vista ordenada.
- Permite personalizar nombre, RUC, subtítulo y logo.
- Exporta un PDF vertical tipo comprobante.

## Ejecutar
```bash
bun dev
```

## Tecnologías
- Next.js
- React
- Tailwind CSS
- jsPDF
